
# Textbook Store App

A peer-to-peer second hand textbook marketplace.




## Overview

The Textbook Store App allows students to buy and sell second-hand textbooks. Every listing is attributed to a specific user. Each user is identified by their real details as supplied to their institution of study (e.g. their student email, course, year of study, etc.).
## Features:
- User registration, login and password reset (client-side, in-memory)
- Home screen with a searchable, scrollable catalogue of textbook listings.
- Live search by title, author or ISBN.
- Filter chips (Excellent, Good, Fair, Poor, Lowest Price) that work in tandem with the live search.
- Book details screen with full information and seller details.
- Sell screen to create a listing, including a cover image picker.
- In-app messaging between buyer and seller (conversation list and chat thread).
- Profile and edit profile, including a profile picture picker.
## Technical Details

- Kotlin
- XML layouts with Material 3 components
- SDK 24
